# Code of Conduct

## Our standard

We want Smart Radio Pro to be a welcoming technical project. Contributors are expected to:

- communicate respectfully and professionally;
- assume good intent while discussing disagreements;
- focus criticism on code, behavior, and evidence rather than people;
- welcome useful questions from beginners and experienced contributors;
- avoid harassment, discrimination, personal attacks, and deliberate disruption.

## Unacceptable behavior

Examples include:

- threats or intimidation;
- targeted harassment;
- hateful or discriminatory language;
- publishing private information without permission;
- sustained personal attacks;
- knowingly disruptive or abusive behavior in project channels.

## Enforcement

Project maintainers may remove comments, close discussions, or restrict participation when conduct violates this standard.

For sensitive conduct concerns, contact the maintainer privately through GitHub rather than escalating the situation in a public thread.

This code of conduct applies to repository issues, pull requests, reviews, discussions, and other spaces used for project collaboration.
