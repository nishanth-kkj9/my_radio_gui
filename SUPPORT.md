## Bug reports

Use the repository bug-report template and include:

- application version;
- operating system;
- Python version;
- VLC version and architecture;
- exact error message;
- steps to reproduce;
- relevant log lines from `radio_log.txt`.

Remove secrets and unrelated personal information before posting logs.

## Feature requests

Describe the user problem first, then the proposed behavior. Explain why the change belongs in Smart Radio Pro and identify any compatibility or performance considerations.

## Questions

For questions that are not security-sensitive, use a GitHub issue with enough context for another contributor to reproduce or answer the question.

Please avoid posting duplicate issues when an existing report already describes the same problem.
